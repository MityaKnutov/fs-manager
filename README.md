# Задание 2: Графический интерфейс файлового менеджера (Tkinter GUI)

Настольное приложение с графическим интерфейсом на Python (`tkinter.ttk`) для интерактивного управления файловой системой.

## Возможности

- **Вкладки интерфейса**:
  - **Просмотр и Поиск**: Просмотр списка файлов и поиск по регулярным выражениям (`search_a_like`).
  - **Создание и Удаление**: Создание папок, рекурсивное удаление папок (включая непустые) и удаление файлов.
  - **Перемещение и Копирование**: Перемещение (`move`) и копирование (`copy`) файлов и папок.
  - **Анализ и Даты**: Добавление даты создания в имя файла (`add_date`) и рекурсивный анализ объема (`analyse`).
- **Нативные диалоги выбора**: Кнопки обзора файлов и папок (`filedialog`) с поддержкой ручного ввода пути.
- **Всплывающие подсказки (Tooltips)**: Подсказки при наведении на поля ввода и кнопки.
- **Безопасность и обработка ошибок**: Перехват исключений с выводом диалоговых окон (`messagebox.showerror`) без падения приложения.

## Установка и запуск

```bash
python3 -m venv venv
source venv/bin/activate

# Запуск графического интерфейса
python3 gui.py

# Запуск консольной версии
python3 main.py help

# Запуск unit-тестов
python3 -m unittest tests.py
```
